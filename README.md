# Wayfarer — Offline-First Trip & Expense Planner

Mobile-first PWA inspired by Wanderlog, built with React, TypeScript, Vite, Material UI (Material Design 3 styling), Dexie.js (IndexedDB), Leaflet/OpenStreetMap, Recharts, and `vite-plugin-pwa`.

## Quick Start

```bash
npm install
npm run dev
```

## Production Build & PWA Preview

```bash
npm run build
npm run preview
```
